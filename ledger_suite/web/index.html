WORLD SYSTEMS / PRACTICAL TOOLS

World tools

Use the local CLI for project-root checks and compute break-even estimates.

UNITY PROJECT ROOT

Check root hygiene

Confirm the selected directory contains Assets/, Packages/manifest.json, and ProjectSettings/ProjectVersion.txt.

python -m ledger_suite audit-unity /path/to/UnityProject

Read-only check. It does not repair or modify project files.

CLOUD COMPUTE

Compare monthly run rates

Include persistent storage when comparing hourly GPU use against a flat-rate workstation.

python -m ledger_suite estimate-cloud 15 \
  --hourly-rate 0.50 --storage 14 --flat-rate 60

Uses 52/12 weeks per month; actual provider prices and usage limits vary.

Platform boundaries

This suite does not connect to VRChat, Discord, Patreon, cloud GPU providers, or payment systems. The roster, group checks, moderation decisions, and release records are operator-maintained notes. Client-side Udon logic cannot enforce platform-wide trust ranks or replace VRChat’s own safety and group controls.
